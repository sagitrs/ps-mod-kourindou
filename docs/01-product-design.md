# 产品设计

[返回入口](../README.md) · [待定规则](03-decisions.md) · [验收方案](05-validation.md)

## 1. 定位与范围

在原游戏经营循环上增加东方角色养成，而不是首版重做整部游戏。推荐先交付一个内部模块化的完整Mod，后续再拆可选内容包；这个包装方案是技术建议，不把用户原先允许的1—N个Mod限制成永久只能一个。

以下需求编号用于开发计划和Issue追踪。R01—R08来自用户已明确的目标；R09—R10是为安全实现这些目标提出的工程约束。待定玩法另列D编号，不能用工程建议冒充用户已决定的玩法。

| 编号 | V1要求 |
|---|---|
| R01 | 玩家扮演森近霖之助，初始店名「香霖堂」 |
| R02 | 下城区/魔法森林新增爱丽丝，中城区/人里新增魔理沙，上城区/雾之湖新增咲夜；保留其他原NPC、其他派系及主体剧情 |
| R03 | 对应城区派系好感达到100后可搬迁：更换店面背景，提高当地角色出现概率，不另造地图 |
| R04 | 三人各有独立好感计量条，买店前上限100 |
| R05 | 角色好感达到100后，夜间可以付费获得该角色帮助 |
| R06 | 买下店铺后开放角色好感100—200区间 |
| R07 | 150解锁恋人CG，200解锁结婚CG，作为终局养成内容 |
| R08 | 角色好感达到100后可选每日买家、每日卖家或自然模式 |
| R09 | 进度按局保存，稳定身份不串档；禁用、更新和异常不能默默破坏原存档 |
| R10 | 使用目标版本可验证的适配与最小权限，分发物不夹带游戏文件或未经许可的美术 |

## 2. V1角色与世界

| 角色 | 原城区归属 | 东方地区设定 | 养成内容 |
|---|---|---|---|
| 爱丽丝 | 下城区 | 魔法森林 | 独立好感、夜间帮助、来访模式、恋人/结婚CG |
| 魔理沙 | 中城区 | 人里 | 同上 |
| 咲夜 | 上城区 | 雾之湖 | 同上 |

这份对应关系是用户明确指定，不为贴合原作考据擅自挪动角色。三人是新增访客，不是把现有NPC换名换脸后删除其原身份。可复用本体普通买家/卖家的行为模板，但要有独立角色身份与记录。

原NPC继续出现；警局、革命军等其他派系及剧情服务继续工作。首版不增加其他东方角色、不清理所有赛博文本、不重做派系关系，也不因为主角是霖之助就自动增加鉴定异能、职业加成或特殊剧情。

三个城区的**显示名是否也东方化尚未决定**。内部城区身份和原机制不因显示名变化重建。建议「香霖堂」仅作为新局默认名，保留后续改名，不反复覆盖旧档；旧档启用规则见D09。

## 3. 玩家体验

### 3.1 普通经营与个人好感

三人在正常经营中来访，以买家或卖家身份参加真实交易。好感绑定角色，不绑定临时顾客实例、显示名、头像或买卖身份。角色面板显示当前好感、上限、下一解锁节点与功能可用原因。

好感从哪些行为增长、是否减少、单次值和每日上限尚待D02确认。不能因为有进度条就声称增长机制完成；成功交易、取消交易、失败报价等实际事件需要区分。

### 3.2 搬迁与地区偏好

门槛看**对应原城区的派系好感**，不是爱丽丝等某一人的个人好感。到100后可选择相应东方地区的店面背景。

搬迁仍是同一家店：库存、柜台、金钱、原剧情、房产状态和买店进度不因换背景重建。不把搬迁当作再次购买新店；搬迁费若要存在，需另行确认。

地区加权至少覆盖相应新增角色。是否同时提高同城区原NPC权重、倍率多少、何时生效、声望下降是否重新锁定均见D04/D05。加权必须进入真实顾客选择流程，而非只修改界面文字。

### 3.3 夜间付费帮助

角色好感达到100后，在夜间入口选择该角色的帮助，明确显示费用、具体效果、次数/冷却以及不可用原因。爱丽丝、魔理沙、咲夜的具体效果和价格尚未指定，不能用统一的空按钮或仅扣钱代替帮助。

实现应在点击时重新检查条件，避免双击重复支付；效果失败时按照该效果的可验证恢复策略处理。游戏没有通用数据库事务，不能笼统宣称所有效果都“原子成功”。

### 3.4 买店与CG终局

买店前上限100；读取本体**真实买店状态**后开放到200，不能用现金够买店或房租为零替代。新购店事件与已经买店的旧档都需覆盖。

达到或跨过150、200分别登记两种CG解锁。不得只比较数值恰好相等，跳过阈值时仍要解锁；一次跨过两档不得相互覆盖。买店本身不自动给好感，买店前溢出是否储存待D07确认。

CG解锁、播放、回看、关系状态应分开考虑。多角色恋爱/婚姻、是否告白/求婚、是否跨档收藏仍是D08，没有默认加入单配偶或嫉妒机制。缺图必须提示缺素材，不能把占位图算作正式CG交付。

### 3.5 每日来访模式

三个互斥选项：

| 模式 | 目的 |
|---|---|
| 自然 | 不作个人每日保底，地区偏好仍可生效 |
| 每日买家 | 每日以向玩家购买商品的身份来访 |
| 每日卖家 | 每日以向玩家出售商品的身份来访 |

每日模式需要确定性计划，不是把随机权重调大。入队不等于已到柜台，来访也不等于成功成交，三者应分别记录。自然抽样和保底调度必须去重并尊重角色身份。

模式生效日、一天次数、是否增加总客流、提前关店等例外见D06。原剧情不能被抢占；若保底无法满足，必须暴露原因，不能暗中改为多日轮换。

## 4. 明确的非目标

V1不交付全NPC随机替换、不清除全部赛博设定、不重写原剧情、不扩大角色数，不自动增加赠礼、联机、约会地图、时间操控或永久婚姻惩罚。建议的扩展点不等于这些功能已加入范围。

## 5. 最终目标

最终要**把所有NPC随机替换为东方角色，并清理赛博设定**。这包括不能永远排除关键剧情NPC；清理也不能只换头像，需要后续逐项盘点人物、组织、文本、对白、物品、场景和界面等内容。

随机按每局固定、每次生成重抽、分池或不重复抽取尚未决定。技术上建议区分“原NPC功能身份”和“东方角色身份”，保持好感和剧情的可追踪性，但不在V1提前实施随机替换器。

最终目标的角色池、改造清单、随机规则、版本号和验收标准另行设计。首版通过不代表最终目标完成，最终目标未完成也不应阻塞已满足本范围的V1交付。

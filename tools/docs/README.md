# 文档检查工具索引

本目录是当前仓库唯一测试工具根，入口声明见[仓根README](../../README.md)。现阶段仅验证设计文档，不涉及Mod运行；以后产品测试入口由工程任务另行建立并统一维护索引。

## 工具与用法

| 文件 | 用途 | 命令（仓根） |
|---|---|---|
| [check_docs.py](check_docs.py) | 文档文件链接、Issue规划与引用结构校验 | `python3 tools/docs/check_docs.py` |
| [test_check_docs.py](test_check_docs.py) | 实际调用上述CLI，覆盖有效输入、错误结构和失效输入 | `python3 tools/docs/test_check_docs.py` |

Python 3.11或更高版本，仅标准库、无网络请求。检查器也接受显式根目录：`python3 tools/docs/check_docs.py /path/to/checkout`，默认根按脚本位置确定，不依赖当前目录。

## 判据与边界

- 读取README、`docs/**/*.md`、`planning/**/*.md`、本索引及`planning/issues.json`；不遍历`.git`、构建产物或游戏资产。
- 检查普通内联Markdown文件链接、输入路径/符号链接、非空文档和尾随空白。不作完整Markdown语法或自然语言理解；带片段的仓内链接明确拒绝，不能默默假定锚点正确。
- 索引schema为3：17项规划，GOAL、V1及12项开发任务映射14张Issue；F三项不能伪造远端号。核正整数编号、编号/本仓URL一致、编号唯一及正文映射一致；主票仍固定#1。实际远端身份和原生关系必须另行GitHub读回，离线工具不请求API，也不能仅凭自洽数据证明票真的存在。
- 核父子关系、依赖无环、正文标题/标记/引用、R01—R10、AC01—AC20、D01—D13及首版任务的结构覆盖。编号被引用不代表内容语义完整或产品验收通过。
- 发布范围已由“仅主Issue”变为“主票＋V1＋12张开发子票”。以后获准发布更多票时，要同步schema/发布口径、文档和断言，不能删除守卫以逃避真实变更。JSON统计的`mapped_main_issues`已改为`mapped_issues`，避免把14张票误称为14张主票。

退出码：0=本声明范围内结构有效，1=文档/规划不符合当前约定，2=输入缺失、无法解析或不安全。缺输入不冒产品语义失败。

自测执行31个方法，通过实际CLI观察退出码和诊断；默认根与显式根均有正例，包含缺文件、重复JSON键、非法数、重复/缺任务、循环依赖、错误主票/假后续票、缺少已发布映射、重复远端号、错误仓URL、旧发布范围、正文映射缺失、子票布尔/非正编号、越界路径和缺覆盖等反例。自测需要可写的用户`~/tmp`，只在唯一临时目录中建副本并清理，不写共享`/tmp`。符号链接测试需要操作系统允许创建符号链接；权限不足报环境错误，不静默跳过当通过。

自测成功预期为`Ran 31 tests`和`OK`；空套件明确返回2，不能零执行报绿。重复执行不增加覆盖数量。正式值以实际输出为准。删除库存完整性守卫后，重复任务用例应失败；删除映射有效性守卫时，错误远端URL用例应失败；把检查器替换为恒成功程序时，负例必须失败。

本笔没有CI工作流，两个命令是当前实际可调用入口，不宣称远端CI已执行。这些工具不能证明游戏API、扫描器、存档兼容、图片许可或任何20项产品功能验收已完成，也不证明候选规则已经用户批准。
